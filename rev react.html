Resumo Rápido React

1. Instalar e iniciar projeto com Vite

# Instalar Node.js: https://nodejs.org/en/download/
npm create vite@latest
# Escolher React + JavaScript
cd nome-do-projeto
npm install
npm run dev

2. Estrutura base App.jsx

import './App.css'

function App() {
  return (
    <div className="App">
      <h1>Hello React!</h1>
    </div>
  );
}

export default App;

3. Criar Componente em outro arquivo

// MyButton.jsx
export function MyButton() {
  return <button>Clica aqui</button>;
}

// App.jsx
import { MyButton } from './MyButton';

function App() {
  return (
    <>
      <h1>Exemplo</h1>
      <MyButton />
    </>
  );
}

4. Regras básicas JSX

- Um componente deve retornar apenas 1 elemento. Use <></> (Fragment) se precisar.
- Nome de componente deve começar com MAIÚSCULA.
- Para escrever JavaScript dentro do JSX, use { }.

5. Estilização

6. Exemplo com MUI (Material UI)

npm install @mui/material @emotion/react @emotion/styled

// App.jsx
import Button from '@mui/material/Button';
import ShoppingCartIcon from '@mui/icons-material/ShoppingCart';

function App() {
  return (
    <Button
      variant="contained"
      startIcon={<ShoppingCartIcon />}
      onClick={() => console.log("Clicado!")}
    >
      Adicionar ao Carrinho
    </Button>
  );
}
