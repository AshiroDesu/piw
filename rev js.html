1. Revisão - Aula 1: Fundamentos JS

Variáveis: let, const, var

Tipos: number, string, boolean, undefined, null, object

Operadores: +, -, *, /, %, ==, ===, &&, ||, ?

Estruturas:

if (cond) { ... } else { ... }
for (let i = 0; i < 5; i++) { ... }
while (cond) { ... }

Arrays: map, filter, reduce

Objetos:

const pessoa = { nome: "Ana", idade: 20 };
console.log(pessoa.nome);

2. JS - Aula 2: Funções, Classes, DOM

Funções:

// Normal
function somar(x, y) { return x + y; }

// Arrow Function
const subtrair = (a, b) => a - b;

Classes:

class Animal {
  constructor(nome) {
    this.nome = nome;
  }
  falar() {
    console.log(this.nome + " fez um som");
  }
}

class Cachorro extends Animal {
  falar() {
    console.log(this.nome + " latiu!");
  }
}

DOM:

document.getElementById("meuId")
document.querySelector(".minhaClasse")
document.querySelectorAll("p")

Eventos:

document.getElementById("btn").addEventListener("click", () => {
  alert("Clicou!");
});

Alterando conteúdo/style:

element.innerText = "Novo texto";
element.style.color = "red";

3. JS - Aula 4: Assíncrono, Promises, Async/Await

Callback: função passada como parâmetro.

Promise:

const promessa = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Sucesso!"), 1000);
});

promessa.then(console.log);

Async/Await:

async function exemplo() {
  try {
    const res = await fetch("https://hp-api.onrender.com/api/characters");
    const data = await res.json();
    console.log(data);
  } catch (e) {
    console.error("Erro:", e);
  }
}
exemplo();
