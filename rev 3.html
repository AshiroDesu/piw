Conceito de Código Assíncrono

JavaScript é single-threaded. Para não travar a interface durante operações demoradas, usamos código assíncrono.

Enquanto espera pela resposta de um servidor, o JS continua executando outras tarefas.

Callback vs Promises

// Callback (forma antiga)
setTimeout(() => {
  console.log("Executou depois de 1 segundo");
}, 1000);

// Promise (forma moderna)
const promessa = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Sucesso!"), 1000);
});

promessa.then(res => console.log(res));

Promise Chaining

fetch("https://hp-api.onrender.com/api/characters")
  .then(res => res.json())
  .then(data => {
    console.log("Personagens:", data);
  })
  .catch(err => console.error("Erro:", err));

Async / Await

async function buscarPersonagens() {
  try {
    const resposta = await fetch("https://hp-api.onrender.com/api/characters");
    const personagens = await resposta.json();
    console.log("Personagens:", personagens);
  } catch (erro) {
    console.error("Erro:", erro);
  }
}

buscarPersonagens();

Promise.all vs Promise.any

const p1 = fetch("/api1");
const p2 = fetch("/api2");

Promise.all([p1, p2])
  .then(res => console.log("Todas as promessas resolvidas"));

Promise.any([p1, p2])
  .then(res => console.log("A primeira resolvida foi:", res));
